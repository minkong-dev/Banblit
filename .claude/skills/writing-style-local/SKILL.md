# Banblit 글쓰기 보충

전역 `writing-style` 스킬의 규칙 위에 이 저장소에서 확정된 표기만 적습니다. 아래 표기는 다시 묻지 않고 적용하고,
저장소의 옛 주석·문구가 다른 표기를 써도 따라 쓰지 않습니다. 2026-10-07 에 개발자님이 확정했습니다.

## 확정 표기 (다시 묻지 않는다)

| 쓰는 이름 | 쓰지 않는 이름 | 비고 |
|---|---|---|
| 집중 합주기간 | 집중합주 기간, 집중기간 | 띄어쓰기 고정 |
| 전체 합주 | 전체합주 | 띄어쓰기 고정. 옛 코드·문서에 "전체합주" 가 남아 있어도 새 글은 "전체 합주" |
| 팀별 합주 | 팀별합주 | 띄어쓰기 고정 |
| 공연명 | 기간 이름 | `periods.name` |
| 합주실, 합주실명 | 방, 연습실, 합주실 이름 | |
| 포지션 | 악기 | |
| 배정기록 | 회차 | 화면 문구는 "이전 배정기록" |
| 권한 세트 | 권한 묶음 | |
| 불가능 일정 | 불가능 시간 | 서버 열 이름이 `unavailable` 이어도 글은 "불가능 일정" |
| 시작 시간 / 종료 시간 | 시작 시각, 끝 시각, 시작, 끝 | 시간 입력 라벨·검증 문구 전부. 여러 번 지적받음 |
| 버튼 | 단추 | |
| "<대상> 아이콘" | 벨, 종 | 모양은 적지 않음 |
| 시각 표기 | 칸 | 화면에서 "칸" 을 쓰지 않음. 칸(slot)은 계산 엔진의 단위 |
| 존재하지 않는 X입니다, X가 존재하지 않습니다 | 그런 X이 없습니다, X가 없습니다 | 없는 대상을 조회한 오류 문구, 대상의 부재를 말하는 모든 문장 |
| 테스트 도구(pytest·mypy·vitest·lint) | 검사 도구 | 도구는 이름이나 "테스트 도구" 로 부름. "검사" 는 동작(타입 검사, 입력 검증)에만 씀 |
| 수정·삭제·추가·변경·선택·해제·설정·지정·배치·반려 | 고치기·지우기·넣기·바꾸기·고르기·비우기·정하기·서다 | 동작은 한자어 + 하다/됩니다. 답변·주석·문서·화면 전부 |
| 공백, 쉼표, 마침표 | 가운뎃점(·) | 값 사이는 공백, 단어 나열은 쉼표, 문장 이어붙임은 마침표 |

## 제품 이름

- 서비스 이름은 `Banblit`(코드·문서), 화면 로고는 `banblit`(CI 심볼). 한글로 바꿔 쓰지 않습니다.
- 제품 용어는 그대로 둡니다 — 합주실, 기간, 집중 합주기간, 전체 합주, 팀별 합주, 배정, 조율안, 소속, 포지션, 공지사항, 팀 게시판, 불가능 일정, 예약, 반려, 블라인드, 스케줄링.

## 분야 용어 (원문 그대로 + 첫 등장에 정의)

slot(1시간 단위 시간 칸), endpoint, session, cookie, refetch, polling, dialog, modal, toast, rail(본문 오른쪽 칸), migration,
transaction, grid, CP-SAT, OR-Tools, 스크린 리더, aria-label, 포커스. 한글 비유(낭독기·되묻기·통로·날짜 창·껍데기)로 바꾸지 않습니다.

## 문서별 고유 규칙

| 문서 | 규칙 |
|---|---|
| 개발일지 `dev_history/YYYY-MM-DD.md` | 맨 앞 "지금 상태"(무엇을 하던 중, 어느 파일이 어떤 상태, 다음 한 걸음), "용어" 표(`\| 말 \| 뜻 \|`), 트러블슈팅은 무엇이·왜·어떻게, 맨 끝 "남은 것". 커밋 목록은 적지 않음 |
| `.cluedoc/*/README.md` | 문서 버전 `x.y.z draft`, "어떻게 확인했나" 절에 테스트 파일 경로·시나리오·실행 명령. 사용자 결정은 날짜와 함께 |
| `COMMAND.md` | 실행해 확인한 명령만. 실행 경로·용도·옵션 전부의 뜻(생략 시 기본값)·주의점 |
| 화면 문구 | 안내문은 "~해요" 체("가입한 멤버의 목록이에요"). 동작 버튼은 한자어 명사형("저장", "삭제", "반려", "글쓰기"). placeholder 는 "~을 입력해주세요." |
| 코드 주석 | "~합니다" 체. 사용자 결정은 "(사용자 결정 YYYY-MM-DD)" 로 표시 |
