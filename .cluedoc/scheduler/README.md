└─ 주 보기 ── 모드 없음: 시간 세로 전개 · 좌우 스크롤 · 모든 팀 표시

## Abstract

스케줄러는 Banblit에서 가장 큰 자리를 차지하는 메인 화면이다. 캘린더 형태로 일정을 보여주며, 월 보기와 주 보기를 오갈 수 있다. 월 보기는 상단 탭으로 세 가지 모드(전체 팀 일정, 합주실 예약, 내 일정)를 전환한다. 주 보기는 모드 구분 없이 모든 팀의 하루 일정을 시간 순서로 펼쳐 보여준다. 공지사항과 팀찾기도 이 메인 화면에 함께 둔다.

## Introduction

여러 팀의 일정, 합주실 예약, 그리고 내 개인 일정은 성격이 다르지만 모두 같은 달력 위에서 벌어진다. 이걸 화면마다 따로 두면 오가기 번거롭다. 그래서 하나의 캘린더에 모드를 두어, 보고 싶은 관점으로 전환하도록 한다. 여기서 보이는 일정은 데이터베이스의 내용을 그대로 가져와 표시하는 것이며, 일정을 만드는 계산은 [자동 배정](../auto-assignment/README.md)이 따로 담당한다.

## Description

**월 보기 — 세 모드.**

| 모드 | 표시 | 날짜 클릭 시 |
| --- | --- | --- |
| 스케줄러 | 모든 팀 일정, 각 팀은 심볼(색·아이콘·글자)로만 | 그 날의 시간별 타임라인 모달 |
| 예약 | 합주실 예약 상황 | 빈 날짜 클릭 시 예약 모달 |
| 퍼스널 | 내 소속팀 일정 + 내 불가능 시간 | 타임라인 모달(불가능 시간 추가 버튼 포함) |

**주 보기.** 모드 구분 없이, 하루를 시간 축으로 세로로 펼치고 좌우로 스크롤하며 여러 날을 넘긴다. 모든 팀의 일정이 함께 보인다.

**예약 상호작용.** 예약 모드에서 빈 날짜를 누르면 예약 모달이 뜬다. 상시 개방기간에는 개인 또는 팀이 시작·끝 시간을 골라 선착순으로 예약하고, 취소·변경할 수 있다. 예약 규칙의 자세한 내용은 [합주실과 기간](../practice-room-and-periods/README.md)에서 다룬다.

**개인 일정 입력.** 퍼스널 모드의 타임라인 모달에서 불가능 시간을 직접 추가한다. 같은 일을 말로 하는 방법은 [LLM 도우미](../llm-assistant/README.md)가 맡는다. 별도의 마이페이지는 두지 않고, 개인 일정 관리는 퍼스널 모드로 모은다.

**주변 요소.** 화면에는 토글형 사이드바 메뉴가 있고, 프로필 아이콘을 눌러도 사이드바가 열린다. 공지사항과 팀찾기는 메인 화면에 함께 배치한다.

## Conclusion

스케줄러는 결과를 보여주는 창이다. 그 결과가 어떻게 만들어지는지는 [자동 배정](../auto-assignment/README.md)에서, 개인 일정을 말로 다루는 방법은 [LLM 도우미](../llm-assistant/README.md)에서 이어진다.
