## 트러블슈팅

- **무엇이**: 개발 서버에서 `/social` 이 빈 목록을 반환해 버튼이 비활성 상태였습니다. **왜**: `docker-compose.yml` 의 api 가 환경변수를 이름별로 선택해 전달하는 구조라 `.env` 에 넣은 소셜 키 4개가 container 에 들어가지 않았습니다. **어떻게**: api 의 environment 에 4줄을 추가했습니다(`f27e607`). 이 수정이 없으면 배포 서버에서도 같은 증상입니다.
- **무엇이**: `secrets.compare_digest(state, cookie)` 가 비 ASCII state(`?state=한`)에서 TypeError 로 500 을 냈습니다(fastapi 리뷰 지적). **왜**: str 인자는 ASCII 만 허용합니다. **어떻게**: utf-8 bytes 로 비교하고 한글 state 테스트를 추가했습니다.
- **무엇이**: callback 이 실패 사유 문장을 `?detail=` 에 그대로 붙여, 아무 문장이나 담은 링크가 앱 toast 로 표시될 수 있었습니다(security 리뷰 지적). **어떻게**: 서버는 code 4개만 붙이고 화면이 표로 문장을 만듭니다. 모르는 code 는 기본 문구입니다.
- **무엇이**: `urlopen` 의 예외 중 연결 끊김(RemoteDisconnected, IncompleteRead)과 ConnectionResetError 가 잡히지 않아 500 이 될 수 있었습니다. **어떻게**: `(OSError, http.client.HTTPException, ValueError)` 로 넓히고 원인은 로그에만 남깁니다.
- **무엇이**: 같은 소셜 계정을 동시에 연결하면 unique 제약의 IntegrityError 가 500 이 되었습니다. **어떻게**: commit 에서 잡아 rollback 하고 SocialError(taken) 으로 바꿨습니다. 테스트는 commit 을 바꿔치기해 재현합니다.
- **무엇이**: 새 파일을 Write 도구로 만들면 LF 로 생기고 기존 파일은 CRLF 라, 파일 끝에 문자열을 이어 붙인 2개 파일(`account.test.ts`, `hooks.ts`)에 줄바꿈이 섞여 편집 script 의 치환이 실패했습니다. **어떻게**: 파일 전체를 CRLF 로 통일했습니다. 편집 script 는 파일의 줄바꿈을 감지해 치환하므로 새 내용을 이어 붙일 때도 같은 규칙을 지켜야 합니다.
- **무엇이**: 화면 `Settings.test.tsx` 의 `Me` fixture 가 새 필수 field `linked_social` 이 없어 typecheck 에 실패했습니다. **어떻게**: fixture 에 빈 배열을 추가했습니다. 단정문은 바꾸지 않았습니다(field 추가는 호환 변경).
