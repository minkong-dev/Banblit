## 오늘 한 것

### 1. 화면 정비
- 프로필: 설정에서 옮겨 온 CSS 가 `settings.css` 범위에 남아 버튼이 글자만 보이고 입력칸이 붙어 있었습니다.
  이후 와이어프레임을 받아 **표시 상태 ↔ 편집 상태**로 다시 만들었습니다(가운데 원형 사진, 오른쪽 위 연필 → 취소/저장,
  저장 한 번). 사진 변경은 "프로필 사진 변경" 말풍선(업로드·기본 이미지 적용). 테마는 상단바 아이콘으로 되돌렸습니다.
- 대시보드 달력: 넓은 창에서 한 달이 스크롤 없이 한 화면에 들어옵니다.
- 모바일: 기준 기기를 **갤럭시 S24(360×780)·아이폰 17(402×874)** 로 정하고(사용자 결정) 두 폭에서 전 화면을
  캡처해 고쳤습니다 — 한글 낱말 단위 줄바꿈, 달력 일정은 팀 색 막대, 날짜 dialog 잘림, 알림 말풍선 화면 밖,
  계정 화면 최소 폭 420px 제거, 랜딩 3단은 좌우로 넘기는 카드, 멤버 표는 사람당 한 묶음, 예약 달력 글씨 축소.

### 2. 배정 계산
개발 DB 에 40명·12팀 시드를 넣고 개발자님이 직접 돌려 본 결과로 고쳤습니다.
- **횟수 표시 제거**: 같은 7시간이라도 붙은 묶음 수가 실행마다 2·3·7회로 달랐습니다. 시간만 표시합니다.
- **연속 배정**: 목적함수가 없어 조건만 맞으면 흩어졌습니다. "같은 팀·같은 합주실의 이어지는 칸 쌍"을 최대화합니다.
  증명을 못 해 매번 상한 60초를 다 써서, 첫 해를 찾은 뒤 개선은 3초만 합니다(12팀 기준 11팀 한 덩어리).
- **팀당 하루 최대(1~3시간)**: 연속만 최대화하니 하루 7시간이 한 번에 붙었습니다. 설정 드롭다운으로 고릅니다.
  합주 1회보다 짧게는 저장되지 않습니다(짧으면 하루 0회가 되어 빈 배정이 조용히 나옴).

### 3. 예약과 집중 합주기간
집중 합주기간을 **만들거나 넓히거나 전체합주를 바꾸면**, 지금 새로 예약하면 거절될 앞으로의 예약을 취소하고
예약자에게 알림("예약이 집중 합주기간과 겹쳐 취소되었어요.")을 보냅니다(사용자 결정). 이미 지난 예약, 전체합주
날짜의 전체합주 외 시간 예약은 남습니다. 취소한 예약은 기간을 줄여도 되살리지 않습니다.

**결정 경위**: 처음엔 "기간 안에 예약이 있으면 기간 저장을 막자"를 권했는데, 개발자님은 "예약을 밀어버리는 게
맞다"고 했습니다. 이어 "남는 칸은 예약 가능한 거지?"라는 질문에 제가 기획서 문장만 보고 "불가"라고 답해 크게
지적받았습니다 — 개발자님은 전에 여러 번 남는 칸 예약을 요청했고, 9/16 에 문서·서버 불일치를 서버가 아니라
문서 쪽으로 맞춘 것이 원인이었습니다. 구현 방식(재계산이 예약을 피함)을 설명하자 **"그냥 예약은 빼자"**로
결정했습니다. **최종: 집중 합주기간 안 예약은 받지 않습니다(남는 칸 포함).**

### 4. 소셜 로그인 결정(구현 전)
첫 소셜 로그인은 학과·학번·기수 추가 입력으로 가입, 기존 계정은 프로필에서 연결, 이메일이 같다고 자동 연결하지

### 로컬 API 기동 실패와 500
- 8000 포트를 다른 프로덕트(asterix-gateway)가 씀 → 그쪽은 멈추지 않고 `docker compose run -d --use-aliases api`
  로 호스트 포트 없이 띄움(화면은 내부망 `api:8000` 으로 붙음).
- 로그인 500: 개발 DB 에 9/23 프로필 사진 마이그레이션이 안 들어가 있었음. 띄우기 전에 확인하지 않았습니다.
- `.env` 교체 후 DB 비밀번호 인증 실패: PostgreSQL 은 볼륨을 처음 만들 때만 비밀번호를 정함. 개발자님이 값을 되돌림.
  기동 확인을 로그인 요청으로 반복하다 로그인 횟수 제한(429)에 걸림 — 확인은 `/api/me` 로 합니다.
