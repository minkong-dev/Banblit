## 트러블슈팅

- **배포 스크립트가 서버에서 세 번 연달아 터졌습니다.** (1) git 이 실행 권한 없이 올려서
  permission denied — `git update-index --chmod=+x` 로 해결. (2) 백업을 host 에서 뜨려다
  `/srv/banblit/backups` 가 root 소유라 거절 — `backup` 컨테이너를 빌려 그 안에서 뜨도록
  변경. (3) 백업 실패 검사가 파이프의 exit code 를 보고 있었는데 그 exit code 는 `gzip` 의 것이라
  `pg_dump` 가 죽어도 성공으로 읽혔습니다. `banblit.sh` 는 bash 라 `pipefail` 이 있어
  해결됐습니다.
- **배포 후 `/api` 가 전부 502 였습니다.** nginx 가 `proxy_pass` 에 적힌 이름을 기동할 때
  한 번만 풀고 그 주소를 영원히 씁니다. `api` 컨테이너만 다시 뜨면 IP 가 바뀌는데 nginx 는
  옛 주소로 계속 찔렀습니다. 주소를 변수에 담아 요청마다 다시 풀게 수정했는데, **`set` 이
  `rewrite` 와 같은 모듈이라 `break` 뒤에 두면 실행되지 않아** 빈 값이 들어가 이번엔 500 이
  났습니다. `set` 을 `rewrite` 위로 올려 해결했습니다.
- **임시 마이그레이션이 권한 마이그레이션 테스트를 깨뜨렸습니다.** `AFTER = "head"` 로
  끝까지 올리는 테스트인데, 가입한 적 없는 멤버를 삭제하는 임시 마이그레이션이 그 경로에 있어
  테스트가 넣은 두 사람이 사라졌습니다. 테스트가 넣는 행에 `password_hash` 를 채워
  해결했습니다. `head` 로 두는 것은 의도된 것이라(권한 항목이 늘어도 헤드매니저가 전부
  갖는지 확인) 고정 지점으로 바꾸지 않았습니다.
- **설정 행이 테스트 사이에 삭제되었습니다.** conftest 가 매 테스트마다 모든 테이블을 비우는데
  `settings` 한 줄은 migration 이 넣는 schema 의 일부라 61개가 한꺼번에 실패했습니다.
  건너뛰게 했더니 이번엔 값을 바꾼 테스트가 다음으로 새어서, 삭제하는 대신 기본값으로
  되돌리도록 했습니다.
- **타임라인 막대가 시각 격자를 덮고 있었습니다.** 막대가 절대 위치라 나중에 그려져서
  지나가는 시각 줄을 가렸습니다. 줄을 막대 위로 올렸습니다.
