## 트러블슈팅

- **배포 스크립트가 세 번 실패:** 실행 권한 없음(`git update-index --chmod=+x`), root 소유 백업 폴더(`backup` 컨테이너 안에서 백업), 파이프 exit code 가 `gzip` 것이라 `pg_dump` 실패를 놓침(bash `pipefail`)
- **배포 후 `/api` 502:** nginx 가 `proxy_pass` 이름을 기동 때 한 번만 풀어 `api` 재기동 후 옛 IP 로 요청. 변수로 바꿨더니 `set` 이 `break` 뒤라 실행되지 않아 500 → `set` 을 `rewrite` 위로
- **임시 마이그레이션이 권한 마이그레이션 테스트를 깨뜨림:** 가입 안 한 멤버 삭제 migration 이 테스트 행을 지움 → 테스트 행에 `password_hash` 지정
- **설정 행이 테스트 사이에 삭제:** conftest 가 모든 테이블을 비워 61개 실패 → 삭제 대신 기본값으로 되돌림
- **dev 서버 `/api/rooms/1/reservations` 500:** dev DB migration 이 4개 뒤처짐 → `alembic upgrade head`
- **프로필 카드가 열렸다 닫힘:** 화면 이동 시 이전 화면 cleanup 이 `body[data-shell]` 을 지운 사이 자식의 `useFitCount` 가 스타일 계산을 강제 → `data-shell`·`data-page` 를 `useLayoutEffect` 로
- **팀 색 동시 요청:** 마지막 빈 색을 두 요청이 받으면 이름 없는 NOT NULL 오류로 500 → 트리거가 제약 이름 `teams_color_exhausted` 로 거절
- **편집 게이트 훅이 파일마다 첫 편집을 1회 거부:** 같은 파일에 편집 여러 개를 동시에 보내면 일부만 적용됨. 호출처·영향 범위·지시를 적고 거부된 편집만 다시 보냄
- **mypy 검사 대상:** `mypy src` 는 오류 0, `COMMAND.md` 의 `mypy`(인자 없음)는 테스트까지 봐서 2개. 기록된 명령을 씁니다

## 남은 것

### 1. 기능 (순서대로)

1. **전체합주 D단계** — 위 "지금 상태"
2. **배정 job 5분 상한** — 지금은 배정 불가능 입력이면 멤버 수 × 60초까지 걸립니다
3. **권한 집합 race** — `permission_service._require_another_full_set` 이 검사하는 행을 `with_for_update` 로 잠급니다
4. **블라인드** — 팀게시판·공지사항. 블라인드된 글은 작성자 본인도 볼 수 없고(글 전체 격리), 권한자가 격리된 글을 모아 보는 화면이 필요합니다. 타인의 글·댓글 수정은 막고 삭제·블라인드만 허용합니다
5. **Tiptap** — 게시글·공지사항·댓글 입력칸을 Tiptap 하나로(볼드·이탤릭·취소줄·폰트·이미지·링크). 첨부 파일은 등록 전에도 등록 후와 같은 모양으로 미리보기, 받아야 하는 사람만 미리보기 아래 다운로드 아이콘. 대상은 `components/PostBoard.tsx` 의 `postBody`·`editBody`·`editComment` 와 공지 작성. `board.spec`·`notices.spec` 의 `getByLabel("내용")` 도 함께 수정. 설치 승인됨
6. **링크 미리보기** — Vite SPA 라 크롤러가 받는 `index.html` 이 비어 있으므로, FastAPI 가 `index.html` 을 내보낼 때 `og:title`·`og:description`·`og:image` 를 넣습니다
