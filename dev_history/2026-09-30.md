## 트러블슈팅

### e2e 71개 중 60개 이상 실패 — 화면이 아예 뜨지 않음
- **무엇이**: Pretendard 설치 뒤 e2e 전체가 `toBeVisible` 실패.
- **왜**: e2e 컨테이너는 패키지를 `banblit-e2e-modules` volume 에 따로 두는데, `sh -c "npx playwright test"` 로 실행하면
  기본 명령의 `npm install` 을 건너뛰어 새 패키지가 없었습니다. Vite 가 `pretendard` 를 찾지 못해 앱이 렌더링되지 않았습니다.
- **어떻게**: `sh -c "npm install --no-audit --no-fund; npx playwright test"` 로 실행. `COMMAND.md` 12-1-1 에 이미 주의점이
  있었는데 읽지 않았습니다. 다음에 패키지를 추가하면 e2e 는 반드시 `npm install` 을 포함해 돌립니다.

### 360px 폭에서 오늘 칸의 "자동 배정" 글자가 칸 아래로 6.75px 넘침
- **왜**: Pretendard 가 Noto Sans KR 보다 글자 폭이 넓어 11px "자동 배정"이 46px 칸에서 두 줄로 꺾였고, 칸 최소 높이 56px 에
  날짜 26px + 두 줄 27.5px 이 들어가지 않았습니다.
- **어떻게**: 휴대폰 폭의 칸 최소 높이를 56 → 64px, 날짜 줄 높이를 26 → 20px, 칸 위아래 여백을 6/8 → 5/6px 로.
  `layout.spec.ts` 의 기대값도 64 로 수정.
