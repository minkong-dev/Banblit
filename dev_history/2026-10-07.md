## 트러블슈팅

### `python3 -` 가 셸을 120초 멈춤 — 네 번째

- **무엇이**: perl 치환 명령 앞에 `python3 - 2>/dev/null;` 을 붙여 실행했습니다.
- **왜**: 9/30·10/01 개발일지에 세 번 적힌 문제(이 PC 의 `python` 은 Windows Store stub)를 반복했습니다.
- **어떻게**: 작업을 중단하고 perl 만 다시 실행했습니다. **호스트에서 python 을 실행하지 않습니다.** 줄 수 계산도 grep 으로 합니다.

### perl 치환이 적용되지 않음 — 저장소 파일이 CRLF

- **무엇이**: `perl -0pi -e 's/…\n…/'` 로 서버 파일 3개를 고쳤는데 하나도 바뀌지 않았습니다.
- **왜**: 작업 폴더의 파일이 CRLF 라 `\n` 만 쓴 패턴이 맞지 않았습니다.
- **어떻게**: 패턴을 `\r?\n` 으로 바꿔 적용했습니다. 여러 줄 치환은 Edit 도구가 안전합니다.

### Git Bash 가 `/docs/…` 를 Windows 경로로 바꿈

- **무엇이**: `docker compose run -e MANUAL_DIR=/docs/tmpshots` 가 container 안에서 `C:/Program Files/Git/docs/tmpshots` 를 찾았습니다.
- **어떻게**: PowerShell 로 실행했습니다. container 안 절대경로를 인자로 넘길 때는 PowerShell 을 씁니다.

### 모바일 배정 달력의 빈 주가 세로로 긴 것

- **무엇이**: 390px 캡처에서 첫 주 행이 비어 있는데 두 번째 행만큼 길었습니다.
- **왜**: 달력 폭이 620px 고정 + 가로 스크롤이라 금·토 칸이 화면 밖이었고, 그 칸의 일정 3개가 행 높이를 정했습니다. `align-content: start` 는 원인이 아니었습니다.
- **어떻게**: 7열을 폭 안에 넣었습니다.

### 전체합주 체크박스가 4번째 열로 밀림

- **무엇이**: 매일 체크를 4열에 두는 `label:has(.chk) { grid-column: 4 }` 가 전체합주 체크에도 걸렸습니다.
- **어떻게**: 선택자를 날짜 줄로 한정했다가, 체크 2개를 날짜 옆 한 줄로 옮기면서 규칙 자체를 삭제했습니다.

## 개발자님 지적과 반영

- **설명이 길고 결론이 없음** — "뭐라는거야" 지적. 결론 한 문장을 맨 앞에 두고 표로 줄였습니다.
- **구분선·섹션이 있으면 여백을 둔다** — 요소를 선·가장자리에 붙이지 않습니다. 표 양끝 80px, 목록 줄 안쪽 16px, 섹션 사이 28px.
- **성격이 다른 입력은 묶음으로 나누고 소제목을 둔다** — 스케줄링 시간과 합주 시간대를 한 덩어리로 두지 않습니다.
- **종속 옵션은 그 값 옆에** — 매일·전체합주 체크는 날짜 옆.
- **"시작 / 끝" 금지** — 시작 시간 / 종료 시간.
- **가운뎃점 금지** — 공백·쉼표·마침표.
- **묻지 말고 이해를 먼저 정리** — "이해한대로 정리해서 답변해봐". 큰 배치 변경은 이해를 표로 정리해 확정받은 뒤 만들었습니다.
