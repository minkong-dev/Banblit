## 트러블슈팅

### popover 전환 후 e2e 5건 실패
- **무엇이**: 프로필 메뉴가 열린 채 경로 이동 시 사이드바 링크 클릭이 막힘, 사진 변경 팝업이 닫힐 때 초점 미복귀,
  기존 검사 2건이 옛 `.on` class 를 찾음.
- **왜**: popover 가 top layer 로 올라가면 `position: absolute` 가 화면 기준이 됩니다. 브라우저 기본 stylesheet 가
  `[popover]` 에 `inset: 0` 을 주는데 `top`·`right` 만 재정의해 `left: 0` 이 남아, 팝업이 화면 왼쪽 절반을 덮었습니다.
  글자색 팝업은 화면 아래 바깥에 그려졌습니다. 초점은 `hidePopover()` 뒤 브라우저의 초점 정리가 `toggle` 핸들러보다
  나중에 실행되어 다시 빼앗겼습니다.
- **어떻게**: 팝업 4종을 CSS anchor positioning 으로 여는 버튼에 고정했습니다(`shell.css`·`board.css`·`profile.css`).
  초점 이동은 `requestAnimationFrame` 으로 한 프레임 미뤘습니다. 기존 검사는 `.on` 대신 `toBeVisible()`·`toBeHidden()`
  으로 바꿨습니다 — `.on` 이 없어져 그대로 두면 항상 통과하는 검사가 되기 때문입니다.
- **검증**: 폭 360·402·1440px 스크린샷 12장(`trash/2026-09-29-popover-visual-check/`), e2e 69개 통과.
